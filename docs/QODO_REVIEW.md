# Qodo Review Gate

This repository is being built for the TrueForge Hackathon. Substantive changes on `build/trueforge-orchestration` must be reviewed through the pull request before merge.

Review focus for this milestone:

- mission transition correctness and persistence
- supplier discovery provenance and controlled fallback behavior
- handling of unknown commercial values without fabrication
- qualification rules and edge cases
- production authentication/default-deny boundaries
- state migration safety
- TrueForge session/turn integration
- MCP JSON-RPC tool safety and idempotency
- human approval boundary and absence of consequential purchasing tools
- responsive command-center regressions

Do not merge the milestone until review findings are resolved or explicitly accepted with evidence.
